## Resources completeness and canonical connections

The integrated local Resources slice cannot by itself complete the full goal. Its further completeness review must include these additional anchors:

- Responsibility and provenance: `resource_responsibility`, `resource_creator`, `resource_parent_responsibility`, `resource_object_note`, `resource_references`, `access_delegation`, `access_resource_inheritance`. Folder responsibility does not overwrite child contributors or grant provider access.
- Version/retention actions: `resource_revisions`, `resource_move`, `resource_delete`, `resource_link_issue`, `resource_events`, `resource_export_bundle`, `resource_export_security`, `resource_account_history`. Show current/version evidence, safe move/archive consequences, usable Undo and ownership handoff; a link does not freeze or back up provider bytes.
- Provider/security boundaries: `resource_external_folder`, `resource_provider_access`, `resource_link_validation`, `resource_secret_links`, `access_url_disclosure`. Internal folder and external provider-folder link remain distinguishable; no password content or implied provider permission.
- Open input `resource_launch_limits` / `decision-file-policy`: note/resource/revision/folder limits and account/provider ownership. Label provisional limits/policies until decided.
- Deferred `resource_upload`: native stored binaries/uploaded revisions remain outside the adopted links/notes baseline. UI cannot imply an upload/storage service is active.

Required connected journey: `flow-resource-delegation` → `flow-resource-discover` → `flow-resource-assign` → `flow-resource-review`. Its direct prerequisites include `resource_explorer`, `resource_inspector`, `resource_bubbles`, and the Open `resource_launch_limits`. Resources already creates canonical tasks consumed by Project Work, basic My Work and Overview progress; retry IDs prevent duplicate creates. Complete the same-resource detail return and later Schedule/review consumers with one resource/task ID. Do not maintain a second resource-task collection to imitate this connection.

The latest **connected Resources folders, notes and hyperlinks** increment is **Present/Partial with scoped verification**. It adds a full reading surface, explicit Markdown formatting, headings/emphasis/lists, HTTPS link insertion, an existing-resource picker and safe canonical references.
