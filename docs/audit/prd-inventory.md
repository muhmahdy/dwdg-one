## Precedence

1. The owner's latest instruction in chat, then the master prompt (`READ THIS IMPORTANT FOR EVERY AI/DWDG_Semi_ERP_Refactoring_Master_Prompt.md`) for the engineering approach.
2. Owner decisions **D1 to D66** in `.planning/DECISIONS.md`. These are final until the owner changes them.
3. The saved planning workspace (`.planning/dwdg-one-prd/state/planning-workspace.json`), the editable PRD.
4. The prototype's actual behaviour (`frontend/prototype/`). Where it implements a decision or requirement it is the behavioural reference. Where it differs from the PRD, see "Discrepancies" below.
5. Historical material (labelled below). It informs, never overrides.
